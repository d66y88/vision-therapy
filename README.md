# Vision Therapy

弱视与斜视辅助训练系统（Web SPA）。面向 7–8 岁儿童，支持红蓝分视校准、Gabor 视敏度训练、抗抑制 / 立体视 / 扫视等游戏与家长看板。

详见 [PRD.md](./PRD.md)。

## 开发

```bash
npm install
npm run dev
```

## 平台适配

当前形态是 **浏览器 Web SPA**，不依赖原生壳：

| 平台 | 支持方式 | 说明 |
|------|----------|------|
| iPad | Safari / Chrome | 主目标；大按钮与触摸滑动已按触控设计 |
| Mac | Safari / Chrome / Edge | 鼠标点击即可 |
| Windows PC | Chrome / Edge | 同上 |
| Android 平板/手机 | Chrome | 可用，小屏体验次于 iPad |
| iOS / Android App | 尚未打包 | PRD 预留 Capacitor，需要时再封壳上架 |

离线可用：构建产物为静态站点，可本机打开或部署到任意静态托管。距离监测（摄像头）仅在支持 `getUserMedia` 的浏览器上作为选配。

## 游戏与轮换

- 游戏库共 **11** 款：视敏度、抗抑制（含对比度天平）、追随、注视、反应、记忆、**扫视**、**立体视**
- 每 **3 天**自动换一轮「今日清单」，每次随机 **4–6** 款（保证 ≥1 视敏度 + ≥1 抗抑制）
- 所有训练页右上角支持 **全屏**（含 iPad 沉浸式回退）
- 标「眼镜」的需先做红蓝校准；家长区可随时重校
- 医院演示：Gabor → 红蓝天平 → 灯光跳跳
